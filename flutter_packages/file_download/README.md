## tekaly_file_download

Give generated bytes to the user as a file, from a Flutter app, on every
platform: on the web the browser downloads the file, elsewhere a save dialog
asks where to put it.

## Getting started

Not on pub.dev, add a git dependency:

```yaml
dependencies:
  tekaly_file_download:
    git:
      url: https://github.com/tekartikprj/tekaly
      path: flutter_packages/file_download
```

Download a file:

```dart
import 'dart:convert';

import 'package:tekaly_file_download/download_file.dart';

Future<void> exportNotes(String notes) async {
  await downloadFile(
    DownloadFileInfo(filename: 'notes.txt', data: utf8.encode(notes)),
  );
}
```

Once at startup, so that the downloads use the app wide picker (and can be
tested, see below):

```dart
import 'package:flutter/material.dart';
import 'package:tekaly_file_picker_flutter/file_picker_flutter.dart';

void main() {
  initTekalyFilePickerFlutter();
  runApp(const MaterialApp(home: Scaffold()));
}
```

(`tekaly_file_picker_flutter` is a git dependency too, `path:
flutter_packages/file_picker_flutter`.)

### Platforms

| Platform | What happens | Setup |
| --- | --- | --- |
| Web | The browser downloads the file (a click on a blob url, [`tekaly_file_download_web`](../../packages/file_download_web)) | none |
| Android, iOS, Windows | A save dialog (`file_picker`, through [`tekaly_file_picker_flutter`](../file_picker_flutter)), the bytes are written where the user chose | none |
| macOS | Same | the `com.apple.security.files.user-selected.read-write` entitlement (`macos/Runner/*.entitlements`) |
| Linux | A GTK save dialog (`file_selector`) | none |

`file_picker` is never used directly here, everything goes through the
`tekaly_file_picker` interface.

## What to use

| Import | Gives | Use it for |
| --- | --- | --- |
| `download_file.dart` | `downloadFile`, `DownloadFileInfo`, `filenameMimeType`, `anchorSelectorSetDownloadFileInfo` | any file |
| `download_image.dart` | `downloadImage`, `DownloadImageInfo` | an image, the same thing with an image named type |

`DownloadFileInfo` deduces the mime type from the filename extension
(`filenameMimeType()`: txt, json, html, css, js, yaml, ics, pdf, png, jpeg, gif,
webp, svg, ico, mp4, wasm...; `application/octet-stream` otherwise). Pass
`mimeType` for anything else (`text/csv`, `text/markdown`...).
`DownloadImageInfo` uses the same table.

## Common mistakes

* A filename without its extension: the mime type falls back to
  `application/octet-stream`.
* Waiting for a result: `downloadFile` returns nothing. A cancelled dialog is not
  an error, and the web never reports where the file went. When the saved
  location is needed (off the web), call `tekalyFilePicker.saveFile()`
  directly, it returns the uri.
* Slow content on the web: a browser (Safari especially) can block a download
  that starts too long after the tap. Build the bytes *before* the tap, or keep
  an `<a id="download-anchor">` in `web/index.html` and feed it with
  `anchorSelectorSetDownloadFileInfo('#download-anchor', fileInfo)` (a no op on
  the other platforms), so that the user clicks a real link.
* Testing on the web: `downloadFile` does not go through `tekalyFilePicker`
  there, a memory picker records nothing. Test on the VM (`flutter test`).

## Testing

Set the global picker to a `TekalyFilePickerMemory` (dev dependency
`tekaly_file_picker`, `path: packages/file_picker`) and check what was saved:

```dart
import 'dart:convert';

import 'package:flutter_test/flutter_test.dart';
import 'package:tekaly_file_download/download_file.dart';
import 'package:tekaly_file_picker/file_picker.dart';
import 'package:tekaly_file_picker/file_picker_memory.dart';

void main() {
  test('download', () async {
    var filePicker = TekalyFilePickerMemory();
    tekalyFilePicker = filePicker;

    await downloadFile(
      DownloadFileInfo(filename: 'a.txt', data: utf8.encode('Hello')),
    );

    var request = filePicker.saveRequests.single;
    expect(request.fileName, 'a.txt');
    expect(request.mimeType, 'text/plain');
  });
}
```

`filePicker.cancelled = true` simulates a user closing the dialog.
