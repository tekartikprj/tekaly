# Download a file from a flutter app (tekaly_file_download)

`tekaly_file_download` is a thin cross platform download helper: on the web the
browser downloads the bytes (`tekaly_file_download_web`), everywhere else a save
dialog asks the user where to put them (`tekaly_file_picker_flutter`).

## Guidelines

* This package is not on pub.dev, depend on it with a git dependency:

  ```yaml
  dependencies:
    tekaly_file_download:
      git:
        url: https://github.com/tekartikprj/tekaly
        path: flutter_packages/file_download
  ```

* Two entry points, import only what is needed:
  * `package:tekaly_file_download/download_file.dart` exports `downloadFile`,
    `DownloadFileInfo`, `filenameMimeType` and
    `anchorSelectorSetDownloadFileInfo`.
  * `package:tekaly_file_download/download_image.dart` exports `downloadImage`,
    `DownloadImageInfo` and `DownloadImageInfoExtension`.
* `DownloadFileInfo(filename:, data:, mimeType:)` takes a `Uint8List` (what
  `utf8.encode()` returns) and a filename **with its extension**: `mimeType`
  defaults to `filenameMimeType(filename)`, which maps a known extension
  (`.txt`, `.json`, `.html`, `.png`, `.jpg`, `.svg`, `.pdf`, `.mp4`, `.yaml`,
  `.ics`, ...) and falls back to `application/octet-stream`. Pass `mimeType`
  explicitly for anything outside that table (`text/csv`, ...).
* `await downloadFile(fileInfo)` returns nothing: a cancelled save dialog is not
  an error, and the web never reports a path. Do not expect a `File` or a uri
  back; use `tekalyFilePicker.saveFile()` from `tekaly_file_picker_flutter`
  directly when the saved uri is needed off the web.
* Images: `downloadImage(DownloadImageInfo(filename:, data:))` sets the mime
  type from the extension (`image/png` when the filename ends with `png`,
  `image/jpg` otherwise) and then runs the same code path;
  `imageInfo.toDownloadFileInfo()` converts explicitly.
* Off the web the save goes through the global `tekalyFilePicker` when the app
  has initialized it (`initTekalyFilePickerFlutter()` once at startup, see the
  `tekaly-file-picker-flutter-pick-and-save` skill), and through
  `tekalyFilePickerFlutter` otherwise. Initializing the global is what makes a
  download assertable in tests.
* On the web the download is a synthetic anchor click on a blob url, which a
  browser (Safari especially) can block when it happens too long after the user
  gesture. Generate the bytes *before* the tap when the content is slow to
  build, or keep an `<a>` in `web/index.html` and feed it with
  `anchorSelectorSetDownloadFileInfo(selector, fileInfo)` so the browser sees a
  plain user click; that function is a no op on the other platforms, so it is
  safe to call unconditionally.
* Anti-patterns: calling `dart:html`/`package:web` or `file_picker` directly
  (nothing here is platform specific, business code stays plugin free), guarding
  calls with `kIsWeb` (`downloadFile` already does it), and hard coding mime
  type strings instead of the filename extension.
* Testing: set the global `tekalyFilePicker` to a `TekalyFilePickerMemory`
  (`package:tekaly_file_picker/file_picker_memory.dart`) and assert on
  `filePicker.saveRequests`; `filePicker.cancelled = true` simulates a user
  dismissing the dialog, which must not throw.

## Examples

Export data from a button handler:

```dart
import 'dart:convert';

import 'package:flutter/material.dart';
import 'package:tekaly_file_download/download_file.dart';

class ExportButton extends StatelessWidget {
  final List<List<String>> rows;

  const ExportButton({super.key, required this.rows});

  @override
  Widget build(BuildContext context) {
    return ElevatedButton(
      onPressed: () async {
        // Built before the await so the browser still sees the user gesture.
        var csv = rows.map((row) => row.join(',')).join('\n');
        await downloadFile(
          DownloadFileInfo(
            filename: 'export.csv',
            data: utf8.encode(csv),
            mimeType: 'text/csv',
          ),
        );
      },
      child: const Text('Export'),
    );
  }
}
```

Download an image, and reuse its file info elsewhere:

```dart
import 'dart:typed_data';

import 'package:tekaly_file_download/download_file.dart';
import 'package:tekaly_file_download/download_image.dart';

Future<void> saveScreenshot(Uint8List pngBytes) async {
  var imageInfo = DownloadImageInfo(filename: 'shot.png', data: pngBytes);
  // mimeType is image/png, deduced from the extension.
  await downloadImage(imageInfo);

  // Same thing, going through the generic helper.
  DownloadFileInfo fileInfo = imageInfo.toDownloadFileInfo();
  await downloadFile(fileInfo);
}
```

Web: feed an anchor declared in `web/index.html` (`<a id="download-anchor"
hidden>Download</a>`) so a slow-to-generate file is never blocked:

```dart
import 'dart:typed_data';

import 'package:tekaly_file_download/download_file.dart';

/// A no op off the web, safe to call from shared code.
void prepareLazyDownload(Uint8List bytes) {
  anchorSelectorSetDownloadFileInfo(
    '#download-anchor',
    DownloadFileInfo(filename: 'report.pdf', data: bytes),
  );
}
```

App startup, so that downloads use the app wide picker:

```dart
import 'package:flutter/material.dart';
import 'package:tekaly_file_picker_flutter/file_picker_flutter.dart';

void main() {
  initTekalyFilePickerFlutter();
  runApp(const MaterialApp(home: Scaffold()));
}
```

Test, with the in memory picker:

```dart
import 'dart:convert';

import 'package:flutter_test/flutter_test.dart';
import 'package:tekaly_file_download/download_file.dart';
import 'package:tekaly_file_picker/file_picker.dart';
import 'package:tekaly_file_picker/file_picker_memory.dart';

void main() {
  late TekalyFilePickerMemory filePicker;
  setUp(() {
    filePicker = TekalyFilePickerMemory(directoryPath: '/dir');
    tekalyFilePicker = filePicker;
  });
  test('downloadFile saves through the picker', () async {
    await downloadFile(
      DownloadFileInfo(filename: 'test.txt', data: utf8.encode('Hello World')),
    );
    var request = filePicker.saveRequests.single;
    expect(request.fileName, 'test.txt');
    expect(request.mimeType, 'text/plain');
    expect(utf8.decode(request.bytes), 'Hello World');
  });
  test('a cancelled dialog does not throw', () async {
    filePicker.cancelled = true;
    await downloadFile(
      DownloadFileInfo(filename: 'test.bin', data: utf8.encode('1')),
    );
    expect(filePicker.saveRequests.single.fileName, 'test.bin');
  });
}
```
