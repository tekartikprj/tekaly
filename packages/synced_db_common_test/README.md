## synced_db_common_test

Test helpers and shared test suites for synced sources
(`runSyncedSourceTest`, `strictSyncedSourceTest`), used by
`tekaly_sembast_synced_test` and `tekaly_sdb_synced_test`.

## Setup

`pubspec.yaml`:

```yaml
  tekaly_synced_db_common_test:
    git:
      url: https://github.com/tekartikprj/tekaly
      path: packages/synced_db_common_test
```
